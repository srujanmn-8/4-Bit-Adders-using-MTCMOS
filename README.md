🔹 Project Title

Design and Comparative Analysis of 4-bit Adders in 45nm using MTCMOS

🔹 Project Overview

This project focuses on the design, simulation, and performance comparison of multiple 4-bit adder architectures implemented in 45nm CMOS technology using MTCMOS techniques. The objective is to analyze delay and power trade-offs by evaluating multi-threshold devices at the transistor and gate level.

🔹 Tools & Technology

Technology Node: 45nm CMOS

EDA Tool: Cadence Virtuoso

Verification: DRC, LVS, RC Extraction

Analysis Metrics: Delay, Power, Threshold Voltage

Design Style: MTCMOS (Multi-Threshold CMOS)

🔹 Methodology

Designed basic CMOS gates using multi-threshold devices

Built full adder cells using optimized transistor sizing

Constructed 4-bit adder architectures

Performed schematic simulation for functional validation

Executed LVS and RC extraction

Compared delay and power performance

🔹 Key Results

Achieved measurable delay and power variation across adder architectures

High-Vt PMOS reduced leakage power

Low-Vt NMOS improved switching speed

Post-layout RC extraction validated schematic-level trends

🔹 Learning Outcomes

Hands-on experience with MTCMOS design

Practical understanding of delay–power trade-offs

Exposure to full VLSI design flow (schematic → LVS → extraction)
